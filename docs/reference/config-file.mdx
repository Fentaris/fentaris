# Config File

> Configure Fentaris project discovery, runtime entrypoint, endpoint, and local auth directory

Generated projects use `fentaris.json` at the project root. The CLI uses this file to discover the project, run the configured entrypoint, validate local state, and build runtime metadata. `fentaris()` also reads `name`, `port`, and `path` from the nearest project root when those fields are not passed in code.

## Quick Start

```json
{
  "name": "my-proxy",
  "packageManager": "pnpm",
  "entrypoint": "src/index.ts",
  "port": 4000,
  "path": "/mcp",
  "authDir": ".fentaris"
}
```

## Fields

### `name`

Project name used in generated metadata and CLI output.

```json
"name": "my-proxy"
```

### `packageManager`

Package manager used for generated scripts.

```json
"packageManager": "pnpm"
```

Allowed values:

* `pnpm`
* `npm`
* `bun`

### `entrypoint`

Runtime entrypoint run by `fentaris dev` and copied into build metadata.

```json
"entrypoint": "src/index.ts"
```

The file must exist for project health checks to pass. TypeScript entrypoints run through the selected package manager's `tsx` executor.

### `port`

Local port printed by `fentaris dev`, used by runtime checks, and used by `fentaris()` when the application does not pass an explicit `port`.

```json
"port": 4000
```

### `path`

MCP endpoint path served by the generated proxy and used by `fentaris()` when the application does not pass an explicit `path`.

```json
"path": "/mcp"
```

The default local endpoint is `http://localhost:4000/mcp`.

### `authDir`

Directory for local encrypted credentials and CLI auth state.

```json
"authDir": ".fentaris"
```

<Note>
  Generated projects ignore `.fentaris/` in git because it contains local credentials and build output.
</Note>

## Legacy Filename

The CLI can still discover `fentaris.config.json`, but generated projects use `fentaris.json`.

```bash theme={null}
mv fentaris.config.json fentaris.json
```
