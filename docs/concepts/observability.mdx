Fentaris exposes observability through CLI checks, structured logs, runtime health checks, and profiler events.

## Local Checks

```bash theme={null}
fentaris check --offline
fentaris doctor --runtime
```

Use `check` for project validation and `doctor` for environment diagnostics.

## Runtime Profiler

Projects can subscribe to profiler events around MCP calls, policy behavior, transport operations, and runtime lifecycle.
Profiler events are redacted before handlers and sinks receive them. Default redaction covers sensitive keys and common token-shaped string values such as bearer tokens, JWTs, and GitHub PATs.

```ts theme={null}
const runtimeProfiler = profiler()
  .pretty()
  .on("mcp.call.success", (event) => {
    console.log(event.durationMs);
  });
```
