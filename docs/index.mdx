# Fentaris Documentation

> Build and operate a centralized MCP proxy for routing, policy, auth, and observability

Fentaris exposes one MCP endpoint in front of many upstream MCP servers. Use it to route tools, enforce per-user policy, store credentials locally, and inspect runtime health from one place.

## Quick Start

Create a runnable proxy project:

```bash theme={null}
pnpm add -g @fentaris/cli
fentaris init my-proxy
cd my-proxy
cp .env.example .env
fentaris dev
```

The generated project listens on `http://localhost:4000/mcp` unless you changed the port or path during initialization.

<Tip>
  Start with the generated project before hand-writing a proxy. It includes auth, policy, demo upstream servers, and a known-good `fentaris.json`.
</Tip>
