## Start here

Fentaris exposes one MCP endpoint in front of many upstream MCP servers. Use it to route tools, enforce per-user policy, store credentials locally, and inspect runtime health from one place.

1. **Install and run a proxy** in [Quickstart](/getting-started/quickstart).
2. **Use Codex-assisted setup** with the optional [Codex Skills](/getting-started/codex-skills).
3. **Understand the moving parts** in [Architecture](/concepts/architecture) and [Servers and transports](/concepts/servers-and-transports).
4. **Harden and scale** with [Proxy setup](/guides/proxy-setup), [Security](/guides/security), and [Observability](/guides/observability).
5. **Ship a real workflow** using the step-by-step [Tutorial](/getting-started/tutorial) and [End-to-end examples](/guides/end-to-end).

## Quickstart

<Steps>
  <Step title="Install @fentaris/core">
    <CodeGroup>
      ```bash pnpm theme={null}
      pnpm add @fentaris/core
      ```

      ```bash npm theme={null}
      npm i @fentaris/core
      ```
    </CodeGroup>

    This gives you the Fentaris SDK, the high-level proxy app API, transport helpers, governance helpers, and runtime APIs.
  </Step>

  <Step title="Create the proxy app">
    ```ts theme={null}
    import { fentaris } from "@fentaris/core";

    const app = fentaris({
      port: 3000,
      path: "/mcp",
    });
    ```

    `fentaris(...)` returns the high-level proxy app. Configure the public endpoint once, then attach upstream MCP servers to it.
  </Step>

  <Step title="Add MCP servers with app.mcp(...)">
    ```ts theme={null}
    import { stdio, streamableHttp } from "@fentaris/core";

    app.mcp("filesystem", {
      displayName: "Filesystem",
      transport: stdio({
        command: "npx",
        args: ["-y", "@modelcontextprotocol/server-filesystem", "./demo-files"],
      }),
    });

    app.mcp("docs", {
      displayName: "Docs",
      transport: streamableHttp({
        url: "https://docs.example.com/mcp",
      }),
    });
    ```

    `app.mcp(...)` gives Fentaris a stable server name, display label, and transport configuration. Add one call per upstream MCP server.
  </Step>

  <Step title="Start the proxy">
    ```ts theme={null}
    await app.start();
    ```

    You now expose a single MCP endpoint that routes to upstream servers and enforces centralized policy.
  </Step>
</Steps>
