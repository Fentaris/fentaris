Use the declaration helpers for new projects. They keep server declarations, transports, identity, policy, and runtime options in one readable config object.

## Prerequisites

- Node.js 20+ (LTS recommended)
- pnpm or npm

## Quick Start

<CodeGroup>
  ```bash pnpm theme={null}
  pnpm add @fentaris/core
  ```

  ```bash npm theme={null}
  npm i @fentaris/core
  ```
</CodeGroup>

```ts theme={null}
import { fentaris, mcp, stdio } from "@fentaris/core";

const proxy = fentaris({
  servers: [
    mcp("filesystem", {
      displayName: "Filesystem",
      transport: stdio({
        command: "npx",
        args: ["-y", "@modelcontextprotocol/server-filesystem", "./demo-files"],
      }),
    }),
  ],
  port: 3000,
  path: "/mcp",
  name: "fentaris-proxy",
  version: "0.1.0",
});

await proxy.start();
```

## Add a Second Server

```ts theme={null}
const proxy = fentaris({
  servers: [
    mcp("filesystem", {
      displayName: "Filesystem",
      transport: stdio({
        command: "npx",
        args: ["-y", "@modelcontextprotocol/server-filesystem", "./demo-files"],
      }),
    }),
    mcp("custom", {
      displayName: "Custom Tools",
      transport: stdio({
        command: "node",
        args: ["./dist/server.js"],
      }),
      env: (user) => ({
        USER_ID: user.id ?? "anonymous",
      }),
    }),
  ],
  port: 3000,
  path: "/mcp",
});
```

## Add Middleware

```ts theme={null}
proxy.use(async (ctx, next) => {
  ctx.log.info("tool-call", {
    server: ctx.server?.name,
    tool: ctx.tool?.name,
  });

  return next();
});
```

## Connect an MCP Client

Point your MCP client to `http://localhost:3000/mcp`. Fentaris forwards requests to the configured servers.

<Tip>
  Change `port` and `path` in the `fentaris(...)` config to align with your environments.
</Tip>

## Verify Available Tools

If you are working in Node, you can list tools directly:

```ts theme={null}
const tools = await proxy.listTools(undefined, { id: "demo-user" });
console.log(tools.tools.map((tool) => tool.name));
```

## Low-Level API

The class constructors are still available for advanced cases that need explicit object construction:

```ts theme={null}
import { McpProxy, McpServer, StdioTransport } from "@fentaris/core";
```

For normal applications, prefer `fentaris(...)`, `mcp(...)`, and `stdio(...)`.
