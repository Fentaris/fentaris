"@fentaris/client": minor

Add `@fentaris/client`, an end-user CLI (`frs`) that signs in to a running Fentaris proxy with OAuth 2.1 (PKCE, loopback redirect) or an API key, stores credentials in the system keychain, and lists, searches, inspects, and calls governed MCP tools, resources, and prompts with a stable JSON envelope and exit codes.
